# Data Area

This area will hold runtime/demo fixtures introduced in later waves, separated by privacy purpose:
- `private/` — local/private material only;
- `sanitized/` — employer/public-safe fixtures;
- `synthetic/` — unmistakably synthetic scale/failure data.

The actual source PDFs are currently preserved under `context/private_source_documents/` for continuity and must not be exposed in a public release.
