# Versioned Runtime Prompts

These public, versioned templates constrain optional AI-assisted project analysis, product fit,
entity/contact reasoning, research, and executive briefs. The application runs with AI disabled by
default; enabling it still requires the explicit runtime configuration and safety gates.

Prompts are application configuration, not hidden policy. Future prompt runs must log prompt/model version and enforce evidence IDs/structured outputs. No prompt may authorize direct external writes or promote unsupported inference into fact.
